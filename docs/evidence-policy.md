# Evidence Policy

This project distinguishes four states:

- **PROPOSED** — a hypothesis, design choice, or planned experiment.
- **IMPLEMENTED** — software exists and is covered by tests, but no scientific claim follows from implementation alone.
- **PRELIMINARY** — an experiment has produced a result, but it has not yet passed the project's replication and leakage checks.
- **VALIDATED** — an empirical result has a declared dataset/model version, independent evaluation split, statistical uncertainty, and a reproducible run manifest.

No synthetic smoke-test result may be presented as evidence of subliminal learning.

Scientific claims must identify the exact model, dataset, prompt/evaluation protocol, seed policy, code revision, and analysis script used to obtain them.
