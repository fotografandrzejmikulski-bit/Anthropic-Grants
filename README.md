# Anthropic Grants — Subliminal Learning & Mechanistic Interpretability

Research repository for a proposed 16-week AI safety study on detecting and mitigating subliminal transfer of behavioral preferences between teacher and student language models.

## Research question

Can mechanistic analysis of model activations and attribution graphs detect a latent behavioral change induced by training on semantically neutral data generated by a behaviorally altered teacher model?

## Core hypothesis

A teacher model with an intentionally induced behavioral preference may transmit that preference to an identically structured student through apparently benign training data. The project tests whether this transfer leaves reproducible internal signatures that can be detected before the target behavior is strongly expressed at the output level.

## Project scope

The proposed pipeline has four phases:

1. **Model-organism construction** — define a measurable behavioral propensity and create aligned/altered teacher baselines.
2. **Subliminal-learning replication** — train control and treated students on filtered teacher-generated data and quantify behavioral transfer.
3. **Mechanistic analysis** — extract attribution graphs and compare internal representations between groups.
4. **Diagnostic classifier** — evaluate whether graph-derived features discriminate treated and control circuits.

## Status

**Proposal / repository bootstrap.** The repository currently contains documentation and experiment scaffolding only. No claim of successful subliminal transfer or classifier performance is made until supported by reproducible runs and stored evaluation artifacts.

## Reproducibility standard

Every reported result should include:

- model identifier and revision;
- dataset generation configuration;
- training hyperparameters;
- random seeds;
- evaluation set definition;
- exact metrics and confidence intervals where appropriate;
- code version / commit;
- compute configuration;
- enough metadata to reproduce the result without relying on undocumented state.

## Safety boundary

Experiments should use isolated, non-deploying model organisms and simulated behavioral objectives. Do not connect experimental models to real production systems, credentials, destructive endpoints, or sensitive infrastructure. Safety procedures and evaluation boundaries are documented in `docs/safety.md`.

## Evidence policy

The words **PROPOSED**, **PRELIMINARY**, **REPLICATED**, and **VALIDATED** are used deliberately. A hypothesis, target metric, or planned milestone must never be presented as an achieved experimental result.
